GUN SHOP DMO — Facebook Worker (เครื่องที่สอง)

1. แตก ZIP ไว้ในโฟลเดอร์ที่เขียนไฟล์ได้ เช่น Documents\GUN-SHOP-DMO-Worker (path มีเว้นวรรคได้)
2. ติดตั้ง Google Chrome และ Node.js 20 ขึ้นไป
3. ดับเบิลคลิก SETUP-FACEBOOK-WORKER.cmd หนึ่งครั้ง
4. ดับเบิลคลิก START-FACEBOOK-WORKER.cmd และเปิดหน้าหลังร้าน Production
5. กด “เชื่อมต่อ Facebook” แล้ว Login/2FA ใน Chrome Worker ด้วยตนเอง
6. กลับหน้าหลังร้าน กดทดสอบการเชื่อมต่อและ Pair BackOffice
7. เริ่มด้วย DRY RUN, Scheduler OFF และ Pause All ก่อนทดสอบงานจริง

ข้อมูลสำคัญ:
- Browser profile จะเก็บที่ %LOCALAPPDATA%\GUN-SHOP-DMO\FacebookWorkerProfile ของ Windows เครื่องนั้นเท่านั้น ไม่อยู่ใน source/ZIP
- Pair Token เฉพาะ Worker จะเก็บใน worker-pair.json ภายในโฟลเดอร์ profile และไม่ส่งให้หน้าเว็บ/Google Sheet
- หลัง Pair สำเร็จ Worker จะ Pair คืนเองหลัง Restart โดยไม่ต้องใช้ Admin session เดิม
- เปิด BackOffice จากเครื่องอื่นได้ ระบบจะอ่านสถานะ PC2 ผ่าน heartbeat และส่งคำสั่ง Test/Open กลับไปยัง PC2
- งานเบื้องหลังจะไม่ bring Chrome ขึ้นหน้าจอ การเปิด/โฟกัส Chrome เกิดเฉพาะคำสั่งที่ผู้ใช้กดจากเครื่อง Worker
- ต้องเปิด PC2 และโปรแกรม Worker ไว้ตลอดช่วงที่ต้องการทำงาน หาก PC2 ปิด ระบบจะไม่ส่ง Comment และ BackOffice จะแสดง Worker OFFLINE
- ห้ามคัดลอก password, cookie หรือ browser profile ขึ้น GitHub/Google Sheet
- ถ้าขึ้น LOGIN_REQUIRED/CHECKPOINT ให้ทำ Login/2FA/CAPTCHA ใน Chrome Worker เท่านั้น
- ถ้าขึ้น NEEDS_REVIEW ระบบจะ Pause โพสต์นั้นอัตโนมัติเพื่อป้องกัน Duplicate ต้องตรวจ Facebook ก่อน Resume
- รุ่น Worker ที่ต้องแสดงใน /status คือ 20.2.2-performance
- Telemetry เก็บถาวรใน worker-telemetry.jsonl และผลที่ยังรายงานไม่สำเร็จเก็บใน worker-results.json ภายใน FacebookWorkerProfile
- ห้ามลบไฟล์ telemetry/result journal ระหว่างกู้ระบบ เพราะใช้ตัดสินว่ารอบใดส่งแล้วและป้องกันการส่งซ้ำ

อัปเดต / ย้อนกลับอย่างปลอดภัย (ทำบน PC2 เมื่อเจ้าของอนุญาตเท่านั้น):
1. ก่อนเปลี่ยนไฟล์ ตรวจ DRY RUN + Pause All + Posts disabled + Scheduler OFF + Trigger 0 และ Queue PENDING/PROCESSING = 0
2. หยุด Worker และ Chrome Worker เฉพาะบน PC2 ก่อนสำรอง ห้ามเปิด Worker พร้อมกันสองชุด
3. เก็บโฟลเดอร์โปรแกรมเดิมไว้ และสำรอง profile/data ของ PC2 ไว้ในที่ส่วนตัว ห้ามรวม profile/session ลง ZIP ที่เผยแพร่
4. แตก ZIP ใหม่ลงอีกโฟลเดอร์ แล้วเปิด SETUP-FACEBOOK-WORKER.cmd; ห้ามย้าย/ลบ worker-pair.json, worker-results.json/.bak หรือ telemetry ของ profile เดิม
5. ใช้ Windows user และ profile path เดิม ถ้าเคยตั้ง FACEBOOK_WORKER_PROFILE_DIR แบบกำหนดเองต้องคงค่าเดิม ไม่ต้องแก้ค่าถ้าใช้ค่าเริ่มต้น
6. เปิด START-FACEBOOK-WORKER.cmd เพียงชุดเดียว ตรวจ ONLINE/RUNNING/CONNECTED/PAIRED ใน DRY RUN ก่อน ห้าม Resume/Scheduler/ส่ง + ระหว่างตรวจ
7. ถ้ามีปัญหา ให้หยุดชุดใหม่ แล้วกลับมา START จากโฟลเดอร์เดิมพร้อม profile/data เดิม ห้าม Logout/ล้าง session หรือทับ journal ด้วยสำเนาเก่า หากมีงานค้างให้ตรวจ ownership/result ก่อน

Release stability-7 ปรับเว็บและ Apps Script; Worker runtime ยังเป็น 20.2.2-performance เช่นเดิม จึงไม่บังคับ restart PC2 เพียงเพราะอัปเดตเว็บ
